# Bundle d’expérience par défaut

Ce contenu est importé **uniquement lors de la première installation d’une instance vide**. Il fournit une scène 1920 × 1080 neutre, un logo image en bas à droite, une date et une heure lisibles, des emplacements AirPlay/Cast/HDMI, une zone de messages et les règles d’inactivité par défaut. La zone de messages disparaît lorsqu’aucune actualité n’est active.

Il ne contient aucune donnée d’entreprise. L’assistant web remplace ensuite l’identité, le logo, les salles, les médias et les textes. Une mise à jour logicielle ne réimporte jamais ce bundle dans une instance existante.

`preview.png` fournit un aperçu statique du rendu neutre.
